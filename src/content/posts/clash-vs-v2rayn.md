## 三、网络分流机制与规则灵活性对抗

科学上网的最高境界是“无感”。优秀的分流机制能够让国内网站秒开、海外服务加速、敏感应用直连：

### 1. Clash 的 YAML 策略组模型
Clash 使用结构化的 YAML 配置文件，通过 `Proxy Group` 构建了多叉树状的分流策略体系：
- 支持根据延迟自动挑选最快节点的 `url-test`；
- 支持根据哈希轮询分散负载的 `load-balance`；
- 节点列表支持通过正则过滤（Filter）自动提取包含特定国家字样的节点；
- 维护成本极低，机场后端更新节点后，前端规则无需做任何修改。

### 2. v2rayN 的高级路由集模型
v2rayN 引入了基于 GeoIP 和 GeoSite 的精准路由规则集：
- 可以精确指定某个本地应用程序（例如 `telegram.exe` 或特定游戏 `steam.exe`）强制走代理；
- 支持在本地直观编辑路由规则链；
- 适合需要对单机特定软件流量进行显微镜级控制的用户。

## 四、全场景接管与游戏加速能力实测

很多用户在日常使用中会遇到这样的困惑：“为什么我开了代理，在 Windows 终端（CMD/PowerShell）里或者在某些外服独立游戏中，依然连不上网络？”

这是因为普通的“系统代理（System Proxy）”只是在 Windows 注册表中设置了一个 HTTP 代理钩子，只有主动遵守该规范的软件（如 Edge、Chrome 浏览器）才会走代理。而命令行工具、微软商店、外服网游、Telegram 等应用会直接绕过系统代理。

### 1. Clash Verge Rev 的 TUN 模式（降维打击）
- 内置轻量级虚拟网卡驱动（Wintun）；
- 只需在界面点击一下“TUN Mode”开关，系统立即生成一张虚拟网卡，**在网络三层（IP 层）物理接管整台电脑的所有进出数据包**；
- 命令行 `git clone`、`npm install`、外服网游、Docker 容器流量全部瞬间实现无感走代理，无需对每一个软件做任何单独设置。

### 2. v2rayN 的 TUN 实现
- v2rayN 同样支持开启 Tun 模式，但其需要依赖管理员权限安装特定组件，并且对虚拟网卡的分流路由配置相对较为繁琐，偶发与其他虚拟机网卡（如 VMware / VirtualBox）产生路由冲突。
