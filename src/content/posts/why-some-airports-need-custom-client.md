> - **为什么机场要推专属客户端？主要有两大完全不同的商业驱动力**：
>   1. **降低新手小白门槛（良性驱动）**：90% 的普通用户搞不懂什么是节点策略组、TUN模式、Subconverter订阅转换。一键安装登录即用的自研客户端（如 **[飞猫云](/posts/airport-feimao/)**）能让非技术用户在 10 秒内畅享翻墙；
>   2. **商业防盗链与用户生态绑定（中性偏防守）**：防止多名用户拼单共享同一个通用订阅链接，通过自研软件限制同一时间在线设备数；
>   3. **黑产恶意捆绑（极度高危恶性）**：劣质小作坊在封闭的 .exe/.apk 壳中植入挖矿代码、暗中上传浏览器 Cookie 或投放弹窗广告。
> - **核心防坑识别法则**：
>   - **良心大厂的标准**：**“专属客户端提供便利，但依然同时开放通用 Clash / Sing-box / Shadowrocket 订阅链接”**；
>   - **高危机场的特征**：**“死死封锁通用订阅，强制用户必须运行不知名闭源安装包，且杀毒软件频繁报毒”**。

## 二、自研专属客户端的三大正向技术价值

不可否认，对于普通大众而言，开源客户端的高学习门槛是推广科学上网的最大阻碍。优秀的自研客户端具备无法替代的价值：

### 1. 彻底抹平技术鸿沟，解救电脑小白与长辈
传统方式需要教用户：复制订阅 URL → 打开 Clash → 找到 Profiles → 粘贴导入 → 选择代理组 → 打开系统代理开关。任何一个环节出错（如端口被占用、网络代理开关未关导致断网），新手都会彻底抓狂。而正规自研客户端把这全部流程封装在底层，一键开启即连，彻底解决售后痛点。

### 2. 智能链路抗封锁与动态端口跳跃
在自研客户端内部，服务商可以嵌入更复杂的动态路由算法。当检测到某个中继入口被特定运营商干扰时，App 可在后台无感切换至备用内网通道，不需要用户手动刷新订阅。

### 3. 一体化多平台体验一致性
Windows、macOS、Android 乃至 iOS 采用统一的 UI 设计语言与交互逻辑，用户在换设备时不需要重新学习不同的开源软件操作。

## 三、警惕！劣质专属客户端的四大流氓暗桩

如果一家机场**绝对拒绝提供通用订阅**，并且其专属客户端具备以下特征，必须立刻停止使用：

1. **安装时强行要求关闭所有杀毒软件（Windows Defender / 360）**：  
   正规软件即便没有购买昂贵的微软企业签名证书，也不会恶意破坏系统防御。强制要求关杀软往往是为了给注入木马放行。
2. **在浏览器中强行安装未知扩展插件**：  
   借由翻墙便利，在 Chrome / Edge 中暗中植入淘宝京东返利劫持插件。
3. **未开启翻墙状态下 CPU 与网络占用异常偏高**：  
   打开任务管理器发现后台常驻进程持续消耗带宽，说明你的宽带正在被当作商业代理节点转售。
4. **频繁向未知海外 IP 上传系统日志与剪贴板内容**：  
   窃取你复制的密码、私钥甚至聊天记录。

## 五、关于专属客户端的常见问答 (FAQ)

### Q1：为什么 iOS 上的专属客户端往往需要走 TestFlight 方式安装？
因为苹果 App Store 官方严格禁止上架任何带有代理中继功能但未在国区备案的应用。机场服务商为了让没有外区 Apple ID 的国内 iOS 用户能用上软件，通常会利用苹果官方的开发者测试渠道（TestFlight）分发专属客户端。这属于正规合法的测试分发手段，安全性由苹果官方签名保障。

### Q2：使用专属客户端会导致我的上网隐私更容易被机场老板看到吗？
无论是专属客户端还是通用开源客户端，**只要流量经过了代理节点服务器，服务器端都可以看到你访问的目标域名与外网连接日志**。两者的区别在于：开源客户端的代码在本地完全透明，绝不可能在你的电脑本地偷窥私隐；而不良的专属客户端可能在本地偷取未加密数据。因此，选择信誉良好的品牌至关重要。
