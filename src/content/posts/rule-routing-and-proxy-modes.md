> **【核心答案先行 (Answer-First / AEO 精选摘要)】**：  
> - **三大代理模式工作流本质定义**：
>   1. **规则模式（Rule，99% 时间推荐使用）**：**智能交通指挥官**。客户端拦截每个请求，比对预设域名/IP数据库（GeoIP、Loyalsoldier）。访问百度、淘宝、微信、网银时自动「直连（Direct）」，不绕行海外、不消耗流量、本地千兆跑满；访问 Google、YouTube、GitHub 时自动「走代理（Proxy）」；
>   2. **全局模式（Global，仅供临时网络排错）**：**所有流量强行出海**。不管访问境内还是境外，所有数据包全部塞给海外节点。直接导致国内网站打开缓慢、甚至触发网上银行或微信的异地登录风控拦截；
>   3. **直连模式（Direct，旁路放行）**：所有网络请求完全不经过任何代理服务器，直通本地宽带运营商，等同于未启动代理。
> - **两条不可违背的分流铁律**：
>   - **OpenAI / Claude 分流铁律**：绝对不要把 AI 策略组绑定到「香港节点」，因为 OpenAI 与 Anthropic 官方对中国香港 IP 实施 100% 封锁；必须定向分流至「美国、日本、新加坡或台湾」；
>   - **国内金融应用防风控铁律**：确保招商银行、工商银行、支付宝、税务系统强制命中 `DIRECT` 直连规则。

## 一、规则分流底层决策生命周期流程图

当你在浏览器中输入一个网址（例如 `www.bilibili.com` 或 `www.youtube.com`）并按下回车，现代代理内核（Mihomo / Xray / Sing-box）在毫秒内完成以下逻辑链条：

```txt
用户在浏览器发起网络请求
           │
           ▼
【Step 1：DNS 解析嗅探 (Sniffing)】
提取目标域名与端口 (例如 bilibili.com:443)
           │
           ▼
【Step 2：匹配客户端分流规则树 (从上至下执行)】
  ├── 规则 1：DOMAIN-SUFFIX,bilibili.com,DIRECT ────────► [命中！直接放行直连]
  │                                                      本地 1000M 宽带直达，0延时
  ├── 规则 2：DOMAIN-KEYWORD,openai,🤖 AI服务 ──────────► [命中！定向至美国专线]
  │                                                      解锁 ChatGPT 4o
  └── 规则 3：GEOIP,CN,DIRECT ─────────────────────────► [命中！国内 IP 库直连]
           │
           ▼ [若所有规则均未命中]
【Step 3：MATCH (Final 兜底规则)】
默认路由至 🚀 节点选择 (走当前选中的主力海外节点)
```

## 二、常见分流模式的实操对比与场景推荐

| 模式名称 | 英文标识 | 数据流向特征 | 国内网站速度 | 海外网站速度 | 适用场景 |
|---|---|---|---|---|---|
| **规则分流** | Rule | 境内直连，境外代理 | 本地最高网速 | 取决于节点质量 | **日常主力推荐 (99%场景)** |
| **全局代理** | Global | 全设备无差别出海 | 严重变慢且耗流量 | 取决于节点质量 | 排查分流规则失效、外服游戏测试 |
| **直接连接** | Direct | 100% 绕过代理客户端 | 本地最高网速 | 无法打开海外受限网站 | 下载国内超大文件、临时关闭代理 |
| **脚本模式** | Script | 支持 JavaScript 动态判断 | 高度可定制 | 取决于代码逻辑 | 极客按时间/网络接口高级编程 |

## 三、高级分流实操：如何编写优雅高效的自定义规则？

在日常使用中，如果你发现某个特定境外网站走直连很慢、或者某个国内办公系统误走了海外代理，无需重新下载规则，只需在客户端的配置覆盖（Merge / Script）中追加自定义规则：

```yaml
# Clash 自定义规则优先级（严格自上而下匹配，先匹配到的先生效）：
rules:
  # 1. 强制让本地公司内网或特定金融域名直连（防异地风控）
  - DOMAIN-SUFFIX,bank.com.cn,DIRECT
  - DOMAIN-SUFFIX,cmbchina.com,DIRECT
  - DOMAIN-KEYWORD,intranet,DIRECT

  # 2. 强制让特定学术与生产力工具走指定高性能策略组
  - DOMAIN-SUFFIX,github.com,🚀 默认代理
  - DOMAIN-SUFFIX,huggingface.co,🤖 AI与生产力
  - DOMAIN-SUFFIX,notion.so,🚀 默认代理

  # 3. 强制让特定流媒体定向到对应地区的解锁节点
  - DOMAIN-KEYWORD,netflix,🎬 奈飞流媒体
  - DOMAIN-SUFFIX,disneyplus.com,🎬 迪士尼流媒体

  # 4. 广告拦截（直接阻断请求，加速网页加载）
  - DOMAIN-KEYWORD,adservice,REJECT
  - DOMAIN-SUFFIX,doubleclick.net,REJECT

  # 5. 兜底规则（凡是不在上述列表中的未识别境外流量全部走代理）
  - MATCH,🚀 默认代理
```

## 四、DNS 分流与“DNS 污染/泄露”的底层关系

很多人在使用代理时常问：“为什么我明明开了规则模式，国外网页依然偶尔报错或者解析出假 IP？”

这是因为在分流判断之前，操作系统如果把海外域名的 DNS 请求发送给了本地运营商的递归 DNS（如电信 `114.114.114.114` 或联通 DNS），GFW 就会在真实 DNS 响应到达前，抢先伪造一个错误的 IP 地址返回给你的浏览器。这被称为 **DNS 污染**。

### 优雅的解决方案：Fake-IP 与远程解析
现代 Clash Verge Rev 与 Sing-box 客户端普遍采用了 **Fake-IP (虚拟 IP 映射)** 技术：
1. 当浏览器请求 `google.com` 时，客户端本地立即返回一个保留私网段虚拟 IP（如 `198.18.0.1`）；
2. 浏览器立刻建立 TCP 连接发往该虚拟 IP；
3. 客户端拦截该请求后，提取出原始域名 `google.com`，直接把域名塞入加密专线通道，交由海外落地服务器进行真实的远程 DNS 解析；
4. 这种机制**彻底避免了本地 DNS 泄露，使 DNS 解析时间归零，网页加载速度提升 30% 以上**。

## 六、分流常见疑难问题排错 (FAQ)

### Q1：为什么我开了规则模式，偶尔访问国内小网站依然显示来自境外 IP？
因为互联网上的小型长尾网站多达数亿个，开源规则库（GeoIP）不可能做到 100% 实时覆盖。如果某个国内冷门网站使用的域名未在规则库中收录，它就会触发底部的 `MATCH` 规则被当作境外流量处理。解决方法是在客户端中将该域名添加为 `DIRECT` 直连。

### Q2：我玩国内游戏（如英雄联盟国服、原神）时需要关闭代理吗？
如果使用的是**规则模式（Rule）**，通常不需要关闭，因为国服游戏的服务器 IP 位于中国大陆，会自动命中 `GEOIP,CN` 直连规则。但若游戏客户端有特殊的局域网广播防作弊检测，且开启了 TUN 虚拟网卡模式，建议在玩国服竞技网游时将客户端切换至「直连模式（Direct）」以确保获得绝对最低的本地延迟。
