> **【核心答案先行 (Answer-First / AEO 精选摘要)】**：  
> - **什么是机场订阅链接？** 订阅链接本质上是一个带有专属安全 Token 的加密 Web URL。客户端向该 URL 发起 HTTP GET 请求后，机场后端会返回一个经过编码的文本文件，包含所有节点的服务器地址、端口、加密协议与接入密钥。
> - **三步极简通用导入法**：
>   1. **登录机场后台**，在“用户中心”或“仪表盘”找到「便捷导入」或「一键订阅」按钮；
>   2. 复制你的**专属订阅链接**（严禁将该链接分享给他人，否则流量会被盗用）；
>   3. 打开客户端（Clash Verge / Shadowrocket / v2rayN），粘贴 URL 点击「导入 / 获取」，节点列表瞬间自动加载完成。
> - **订阅转换（Subconverter）安全警告**：
>   - **核心风险**：绝对不要在不明第三方搭建的公共免费订阅转换网页（如某些野鸡 `sub.xxx.com`）粘贴包含真实 Token 的机场订阅链接！公共转换站可以在后端静默记录并打包转卖你的全套节点凭证；
>   - **安全姿势**：优先使用机场后台直接生成的原生 Clash / Sing-box 订阅；若必须转换，建议在本地 Docker 中自建纯净的开源 Subconverter 服务。

## 一、各大主力客户端订阅导入图文实操步骤

不同操作系统的主流客户端导入逻辑大同小异，以下为最标准、零出错的标准流程：

### 1. Windows / macOS：Clash Verge Rev 导入教程
```txt
【Clash Verge Rev 导入四步法】
① 打开软件左侧边栏「订阅 (Profiles)」
              │
              ▼
② 在顶部输入框粘贴机场后台复制的 Clash 订阅链接
              │
              ▼
③ 点击右侧「导入 (Import)」按钮，等待进度条完成
              │
              ▼
④ 右键刚刚生成的配置卡片，选择「使用 (Selected)」
   随后前往「代理 (Proxies)」选择节点即可！
```

### 2. iOS：Shadowrocket（小火箭）导入教程
1. 打开小火箭 App，点击右上角 **「+」** 号图标；
2. 在第一行「类型」选择 **「Subscribe」**；
3. 在第二行「URL」框中长按粘贴机场的通用订阅地址；
4. 点击右上角 **「完成（Done）」**，软件会自动向服务器拉取并展开几十个国家节点；
5. 首页选择节点后，打开最顶部的「未连接」总开关，首次连接允许系统安装 VPN 配置描述文件。

### 3. Windows：v2rayN 导入教程
1. 打开 v2rayN，在顶部菜单栏点击 **「订阅分组」** → **「订阅分组设置」**；
2. 点击左下角 **「添加」**，在右侧填入机场别名，并在「可选地址（url）」一栏粘贴订阅链接；
3. 点击「确定」保存；
4. 再次点击顶部菜单栏 **「订阅分组」** → **「更新全部订阅（不通过代理）」**，节点立刻整齐排列于主列表。

## 二、订阅更新失败（Update Failed）排查三板斧

在日常使用中，很多用户会遇到“订阅更新失败 / 网络超时 / 404 / 500”等提示，请按以下顺序快速定位问题：

| 故障现象 | 根本原因分析 | 极速解决手段 |
|---|---|---|
| **提示 Network Timeout / 连接超时** | 机场的订阅下发域名已被本地宽带 GFW 拦截 | 开启客户端现有的备用节点（或者开启直连梯子）后再点击更新；或向机场客服索取无污染的备用订阅域名 |
| **提示 401 Unauthorized / Token Expired** | 账号已欠费、套餐到期或者在后台重置了订阅 Token | 登录机场后台核实套餐余量；若重置了 Token，必须重新复制新的订阅 URL 替换旧配置 |
| **提示 YAML Parse Error (配置文件格式损坏)** | 机场后端配置模板出现语法错误，或下发了明文公告信息 | 检查导入的内容是否为 HTML 网页源码，联系机场技术运维紧急修复模板 |
| **导入后节点全部为红色 0ms / 节点不通** | 机场节点使用了过新的协议，当前客户端内核版本过低 | 将客户端软件（如 Clash Verge Rev）升级至最新官方稳定版，确保包含最新 Mihomo 内核 |

## 三、Subconverter 订阅转换的原理与自建安全姿势

有时我们购买的机场只提供了老旧的 SS / V2Ray 纯文本节点池，无法直接导入 Clash 策略组，此时就需要进行“订阅转换”。

```txt
【订阅转换数据流向与泄露隐患】
机场后端 ──[原版节点Token]──► 第三方转换网页 ──[生成YAML配置]──► 你的客户端
                                    │
                                    ▼ (高危！)
                        黑心站长后台明文捕获 Token
                        转手卖给公网爬虫或挂马
```

### 安全建议：
1. **优先使用正规大厂的原生配置**：目前如 **[光速云](/posts/airport-guangsu/)**、**[飞猫云](/posts/airport-feimao/)**、**[微风网络](/posts/airport-weifeng/)** 等正规入库品牌，后台均支持直接导出符合 Clash Verge、Sing-box、Loon、Surge 标准的一键原生订阅，根本不需要经过任何第三方二次转换！
2. **极客本地 Docker 部署 Subconverter**：  
   如果你有深度定制分流规则的高级需求，建议在群晖 NAS 或本地 Linux 虚拟机通过一行 Docker 命令自建私有转换后端：
   ```bash
   docker run -d --name subconverter --restart=always -p 25500:25500 tindy2013/subconverter:latest
   ```
   数据全部在本地回环地址（`127.0.0.1:25500`）运算，绝无任何外泄风险。
